# retail-demand-forecasting
Prediksi penjualan retail harian menggunakan data time-series 5 tahun (2019-2023) dari 50 toko dan 50 item. Mencakup EDA, feature engineering (lag &amp; rolling features), dan model Random Forest untuk demand forecasting.

Link datasetnya ada di sini
https://www.kaggle.com/datasets/dhrubangtalukdar/store-item-demand-forecasting-dataset
